# video 文件夹

此文件夹用于存放视频轮播背景所需的 MP4 视频文件。

## 文件命名规范

请将您的视频文件命名为：
- `video1.mp4` - 第一个视频
- `video2.mp4` - 第二个视频  
- `video3.mp4` - 第三个视频

（可根据需要添加更多视频，如 `video4.mp4` 等）

## 视频要求

### 推荐规格
- **格式**：MP4 (H.264 编码)
- **分辨率**：1920x1080 (1080p) 或 3840x2160 (4K)
- **时长**：建议 10-30 秒（循环播放）
- **文件大小**：单个视频建议不超过 20MB

### 优化建议
1. 使用 H.264 编码以获得最佳兼容性
2. 视频内容建议为流畅的动态背景素材
3. 避免使用包含大面积白色/高亮内容的视频
4. 确保视频静音（或已混合音频但设置为静音播放）

### 免费视频素材网站
- [Pexels Videos](https://www.pexels.com/videos/)
- [Pixabay Videos](https://pixabay.com/videos/)
- [Coverr](https://coverr.co/)

## 注意事项

1. 视频加载优先级：video1.mp4 > video2.mp4 > video3.mp4
2. 如果 video2.mp4 不存在，系统会自动跳过
3. 如果所有视频都加载失败，会显示渐变后备背景
4. 可以在 `script.js` 中修改 `CONFIG.videoCount` 来调整视频数量
